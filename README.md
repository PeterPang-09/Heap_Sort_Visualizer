# Heap Sort Visualizer

An interactive, step-by-step visualizer for learning how heap sort works. It runs in the browser, with no installs or dependencies.

**Website Link:** https://peterpang-09.github.io/Heap_Sort_Visualizer/

## Features
- Array and binary tree shown side by side, so you can see how the array maps to a heap
- Step-by-step walkthrough with a plain-English explanation at each step
- Colour-coded states: heap, comparing, swapped, and sorted
- Step forward and back, auto play, reset, and adjustable speed
- Custom input (up to 15 numbers) or random arrays
- Automatic dark mode (follows your system theme)

## Run locally
Download `index.html` and open it in any browser.
